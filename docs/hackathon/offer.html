Know what an LLM eval run will cost before it runs.

Plan the spend, lock a budget, and keep a record of what each run actually used. Built for small teams without a finance process for model costs.

Email me about a pilot

What it does today

  1. Estimates the cost of an evaluation run from your own pricing file.
  2. Reserves budget before the run, so two runs can't overspend one pool.
  3. Links each result to the reservation that paid for it.
  4. Reports which runs lack recoverable evidence.

What it does not do

  • It does not read your provider invoice.
  • It does not replace your billing dashboard.
  • It is early software, run by one person.
